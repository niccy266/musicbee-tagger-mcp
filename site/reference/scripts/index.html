    Python Scripts Reference¶

    This page documents the auxiliary execution scripts located in scripts/.

    Release Builder (scripts/build_release.py)¶

    Builds Python wheel distribution and PyInstaller standalone executables for Windows/macOS/Linux.

    • Usage: python scripts/build_release.py

    AI Supervised Agent Loop (scripts/ai_supervised_agent_loop.py)¶

    Runs an automated LLM-supervised loop for tag verification and correction.

    • Usage: python scripts/ai_supervised_agent_loop.py

    OpenRouter Agent Loop Monitor (scripts/scripts/openrouter_agent_loop_monitor.py)¶

    Monitors OpenRouter agent logs and progress.

    • Usage: python scripts/openrouter_agent_loop_monitor.py

    HTTPS MCP Server (scripts/https_mcp_server.py)¶

    Runs the MCP server over HTTPS.

    • Usage: python scripts/https_mcp_server.py

    Supervisor (scripts/supervisor.py)¶

    Supervises server health and background tasks.

    • Usage: python scripts/supervisor.py

    Local Documentation Server (scripts/serve_docs.py)¶

    Builds and serves the documentation portal locally at http://mcp-docs/home.

    • Usage: python scripts/serve_docs.py
